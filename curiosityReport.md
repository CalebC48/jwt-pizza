## AWS

Amazon Web Services (AWS) is the world's most widely adopted cloud platform. It was launched by Amazon in 2006 so that Amazon could provide IT services to other businesses. This became known as cloud computing. This allowed businesses to not have to worry about technical infrastructure or management, and instead they could acquire the servers and resources they needed right away. They now offer over 200 services from data centers all over the world.

### Here are some of the main selling points as described on Amazon’s website:

- **Most functionality**  
  AWS claims to have more services than other cloud providers, as well as more features within those services. They cite having the largest variety of databases as a key example of their broad features.

- **Largest community of customers and partners**  
  AWS claims to have millions of active customers around the world. They state how all types of people and companies use their software. Whether it is used for personal use by individuals, small startups, enterprise companies, or public sector organizations.

- **Most secure**  
  AWS says their platform is built to adhere to strict security requirements from many government agencies, banks, and other highly secure companies. This leads to a very secure and flexible system.

- **Fastest pace of innovation**  
  AWS claims to always have the latest technologies. This allows users to experiment with, and learn from, all the current tech being used in the field.

### Many of the key features AWS is known for having are:

- **Compute**

  - EC2 provides scalable virtual servers
  - Lambda has serverless computing

- **Storage**

  - S3 is object storage
  - EFS is file storage
  - Glacier is archival storage

- **Databases**

  - RDS is a relational database
  - DynamoDB is a NoSQL database

- **Networking**

  - VPC for private networks
  - Route 53 for DNS management

- **AI/ML**

  - SageMaker can be used for ML model development

- **Analytics**

  - CloudWatch can be used for logging

- **Security**
  - AWS IAM for identity management
  - GuardDuty for threat detection

## Azure

Azure launched in 2010 and was developed by Microsoft. It was launched in order to help companies and businesses not have to maintain on-site data centers, and allow them to instead use the cloud. Azure has more than 200 products and services that can be utilized with their many global data centers.

### Here are some of the main selling points as described on Microsoft's website:

- **Most extensive cloud footprint**  
  Azure claims to have more regions than any other cloud provider, allowing businesses to choose what data center fits best. They claim to have 300 data centers in over 60 regions.

- **Built-in security**  
  Azure has an in-house team of over 10,000 security experts that dedicate all their time to protecting and detecting vulnerabilities. Over the next 5 years, Microsoft plans to invest an additional $20 billion into their personal security.

- **Industry-leading AI developer services**  
  Azure contains more than 1800 AI models, allowing clients to choose which AI solution fits their need.

- **Scalability**  
  Azure claims that businesses of all sizes utilize their services. They claim that their services can be scaled to fit any size need.

### Many of the key features Azure is known for having are:

- **Compute**

  - Azure Virtual Machines for virtual servers
  - Azure Functions for serverless computing

- **Storage**

  - Azure Blob Storage for object storage
  - Azure Files for file storage

- **Databases**

  - Azure SQL Database is a relational database
  - CosmosDB is a NoSQL database

- **Networking**

  - VNet for private networks

- **AI/ML**

  - Azure Machine Learning Studio and Cognitive Services APIs

- **Security**
  - Azure Active Directory (AAD)
  - Sentinel

## Compare and Contrast

AWS and Azure offer many similar services, and at the large scale they do not tend to have too many differences. Here are some of the differences I was able to discover:

- **Pricing**  
  At the large scale they tend to have similar pricing, however, Azure has many integrations with their other Microsoft licenses which lead to lots of savings for companies that primarily use Microsoft services.

- **Global Presence**  
  They both have great global presences, but Azure has the broadest coverage overall.

- **Ease of Use**  
  Azure is seen as being complex to newcomers, while AWS has lots of documentation and a user-friendly dashboard. AWS does have a large number of services that can be overwhelming.

- **Hybrid Cloud capabilities**  
  AWS does offer some hybrid services, but Azure is seen as being the lead with businesses that want to manage resources both on-site and in the cloud.

- **Integrations**  
  Azure is primarily built to integrate with other Microsoft products, while AWS is better with third-party integrations.
